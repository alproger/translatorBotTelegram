# TranslatorBotTelegram

TranslatorBotTelegram is a simple Telegram bot made with Python.  
The bot can translate user messages into different languages directly inside Telegram.

## What does it do?

The user sends a text message to the bot.  
After that, the bot shows language buttons.  
When the user chooses a language, the bot translates the message and sends the translated text back.

## Main Features

- Translates text messages in Telegram
- Supports several languages
- Uses simple inline buttons
- Easy to install and run
- Free to use for learning and testing

## Supported Languages

- Uzbek
- Russian
- Arabic
- French
- Turkish
- Spanish
- German
- English
- Italian

## Technologies Used

- Python
- pyTelegramBotAPI
- google_trans_new
- Telegram Bot API
