# 🌍 TranslatorBotTelegram

**TranslatorBotTelegram** is a simple Telegram bot built with Python that allows users to translate text messages into different languages directly inside Telegram.

This project was created as one of my early Telegram bot projects. It helped me understand how Telegram bots work, how inline buttons are handled, and how external translation APIs can be integrated into a Python application.

---

## 🇺🇿 Loyiha haqida

**TranslatorBotTelegram** — bu Python yordamida yaratilgan oddiy Telegram tarjimon bot. Foydalanuvchi botga matn yuboradi, bot esa tarjima qilinadigan tilni tanlash uchun inline tugmalar chiqaradi. Foydalanuvchi kerakli tilni tanlagandan so‘ng, bot matnni shu tilga tarjima qilib qaytaradi.

Bu loyiha mening Telegram botlar bilan ishlash bo‘yicha dastlabki amaliy loyihalarimdan biri bo‘lib, unda quyidagi ko‘nikmalar shakllangan:

## ✨ Features

- Translate user messages inside Telegram
- Inline language selection buttons
- Supports multiple languages
- Simple and beginner-friendly Python code
- Built using `pyTelegramBotAPI`
- Uses Google Translate API package
